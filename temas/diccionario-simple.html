Diccionario Simple

1. ¿Qué es y cuándo se usa?

Un diccionario simple asocia cada clave con un valor (clave → valor). No puede haber claves repetidas: cada clave identifica a lo sumo un valor. Analogía: una agenda de contactos, donde cada nombre (clave) tiene un teléfono (valor); no tendría sentido que el mismo nombre apareciera dos veces con teléfonos distintos.

Se usa cuando necesitás buscar un valor a partir de una clave: legajo → alumno, DNI → persona, código de producto → precio. La operación central es recuperar: dada una clave, devolver su valor.

7 → 100→ 3 → 250→ 5 → 80→ null

2. Interfaz del TDA

Las operaciones del TDA Diccionario Simple y sus precondiciones. Notá que agregar recibe dos parámetros (la clave y el valor) y que claves devuelve un ConjuntoTDA con todas las claves cargadas:

public interface DiccionarioSimpleTDA {
    void inicializarDiccionario();      // Sin precondiciones.
    void agregar(int clave, int x);     // Diccionario inicializado.
    void eliminar(int clave);           // Diccionario inicializado.
    int recuperar(int clave);           // Diccionario inicializado y clave existente.
    ConjuntoTDA claves();               // Diccionario inicializado.
}
💡 Ojo recuperar exige que la clave exista. Para saber qué claves hay (y así recorrer el diccionario o validar antes de recuperar) se usa claves(), que devuelve el conjunto de todas las claves cargadas.

3. Implementaciones

Con lista dinámica (LD)

Cada nodo guarda una clave, su valor y la referencia al siguiente. Para agregar primero se busca la clave: si ya existe se actualiza su valor; si no existe se crea un nodo nuevo al inicio. Como hay que recorrer la lista buscando la clave, las operaciones son O(n).

public class DicSimpleLD implements DiccionarioSimpleTDA {
    class Nodo { int clave; int valor; Nodo sig; }   // Clave + valor + referencia al siguiente.
    Nodo inicio;                                     // Referencia al primer nodo de la lista.

    public void inicializarDiccionario() { inicio = null; }   // Diccionario vacío = lista vacía.

    public void agregar(int clave, int x) {
        Nodo nuevo = clave2Nodo(clave);   // Se busca si la clave ya está.
        if (nuevo == null) {              // Si NO existe, se crea un nodo nuevo al inicio.
            nuevo = new Nodo();
            nuevo.clave = clave;
            nuevo.sig = inicio;
            inicio = nuevo;
        }
        nuevo.valor = x;                  // Exista o no, se (re)asigna el valor: si existía, lo actualiza.
    }

    public int recuperar(int clave) {
        Nodo nodo = clave2Nodo(clave);    // Precondición: la clave existe, así que nodo != null.
        return nodo.valor;
    }

    private Nodo clave2Nodo(int clave) {  // Devuelve el nodo de esa clave, o null si no está.
        Nodo turista = inicio;
        while (turista != null && turista.clave != clave)
            turista = turista.sig;
        return turista;
    }
}

Con arreglo (A)

Se guarda un arreglo de objetos Elemento (cada uno con su clave y su valor) y un entero cant con la cantidad de pares cargados. La lógica de agregar es la misma: si la clave ya está, se actualiza el valor; si no, se agrega un elemento nuevo en la posición libre.

public class DicSimpleA implements DiccionarioSimpleTDA {
    class Elemento { int clave; int valor; }   // Un par clave-valor agrupado.
    Elemento[] elementos;
    int cant;   // Cantidad de pares; apunta a la primera posición libre del arreglo.

    public void inicializarDiccionario() {
        elementos = new Elemento[55];   // Capacidad máxima fijada arbitrariamente.
        cant = 0;
    }

    public void agregar(int clave, int x) {
        int i = clave2indice(clave);    // Se busca el índice de la clave.
        if (i == -1) {                  // Si NO existe, se crea un elemento nuevo al final.
            i = cant;
            elementos[i] = new Elemento();
            elementos[i].clave = clave;
            cant++;
        }
        elementos[i].valor = x;         // Se asigna el valor: si la clave ya estaba, lo actualiza.
    }

    public int recuperar(int clave) {
        int i = clave2indice(clave);    // Precondición: la clave existe, así que i != -1.
        return elementos[i].valor;
    }

    private int clave2indice(int clave) {   // Devuelve el índice de la clave, o -1 si no está.
        int i = cant - 1;
        while (i >= 0 && elementos[i].clave != clave)
            i--;
        return i;
    }
}
💡 Patrón común En las dos implementaciones agregar primero busca la clave y recién después decide: si la encuentra actualiza el valor, si no la encuentra crea el par. Por eso una clave nunca queda duplicada.

eliminar(clave) y claves() (lista dinámica)

eliminar recorre la lista buscando la clave para desenganchar su nodo. Si la clave no está, no pasa nada: el método termina sin tocar la estructura (eliminar una clave inexistente no es un error). claves recorre el diccionario armando un ConjuntoTDA con cada clave cargada:

    public void eliminar(int clave) {
        if (inicio != null) {
            if (inicio.clave == clave) {          // Caso 1: la clave está en el primer nodo.
                inicio = inicio.sig;              // Se saltea el inicio: lo desengancha.
            } else {                              // Caso 2: se busca el nodo PREVIO al que hay que borrar.
                Nodo turista = inicio;
                while (turista.sig != null && turista.sig.clave != clave)
                    turista = turista.sig;
                if (turista.sig != null)          // Si la clave existe, se la saltea.
                    turista.sig = turista.sig.sig;
                // Si turista.sig == null la clave no estaba: no se hace nada (no es error).
            }
        }
    }

    public ConjuntoTDA claves() {
        ConjuntoTDA c = new ConjuntoLD();   // Conjunto vacío donde junto las claves.
        c.inicializarConjunto();
        Nodo turista = inicio;
        while (turista != null) {           // Recorro toda la lista...
            c.agregar(turista.clave);       // ...y voy agregando cada clave al conjunto.
            turista = turista.sig;
        }
        return c;
    }
💡 agregar es un UPSERT agregar(clave, x) hace update-or-insert: si la clave ya existe sobreescribe su valor (no la duplica), y si no existe la inserta. Por eso "modificar" el valor de una clave es simplemente volver a llamar a agregar con el nuevo valor; equivale a eliminar + agregar, pero en un solo paso.
💡 eliminar tolera la clave inexistente eliminar(clave) sobre una clave que no está termina sin hacer nada y sin romper (no tiene como precondición que la clave exista). Esto lo diferencia de recuperar(clave), que sí exige que la clave exista y explota si no.

agregar, eliminar y recuperar son O(n) porque todas necesitan buscar la clave recorriendo la estructura. Si tuviéramos una operación tipo diccionarioVacío, sería O(1) (solo mira si la estructura está vacía, sin recorrer). claves queda en O(n²) porque por cada clave llama al agregar del conjunto, que ya es lineal.

5. Errores comunes

⚠️ Recuperar una clave inexistente recuperar(clave) tiene como precondición que la clave exista. Si no existe, en LD clave2Nodo devuelve null y explota con NullPointerException; en arreglo el índice da -1 y rompe el acceso. Validá antes con claves() si no estás seguro.
⚠️ Agregar una clave existente sin actualizar Como las claves no se repiten, agregar sobre una clave ya cargada debe reemplazar el valor viejo, no crear un par nuevo. Olvidar la búsqueda previa duplica la clave y deja el diccionario inconsistente.
⚠️ Confundir clave con valor En agregar(int clave, int x) el primer parámetro es la clave y el segundo el valor. Invertirlos guarda los datos cruzados y después recuperar devuelve cualquier cosa.

6. Resumen

  • Asocia clave → valor, sin claves repetidas (una clave, un valor).
  • Operaciones: inicializarDiccionario, agregar(clave, x), eliminar(clave), recuperar(clave) y claves().
  • recuperar requiere que la clave exista (precondición).
  • agregar busca primero: si la clave existe actualiza el valor, si no la crea.
  • Buscar la clave hace que agregar/eliminar/recuperar sean O(n) tanto en lista dinámica como en arreglo.
