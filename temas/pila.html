Pila (Stack)

1. ¿Qué es y cuándo se usa?

Una pila es una colección LIFO (Last In, First Out): el último elemento en entrar es el primero en salir. Analogía: una pila de platos — solo podés agarrar el de arriba, y para llegar a uno de abajo tenés que sacar los de encima.

Se usa para: deshacer/rehacer (undo), evaluación de expresiones y balanceo de paréntesis, y para entender cómo el sistema maneja las llamadas recursivas (la pila de ejecución).

tope → 7→ 3→ 5→ null

2. Interfaz del TDA

Las operaciones del TDA Pila y sus precondiciones:

public interface PilaTDA {
    void inicializarPila();   // Sin precondiciones.
    void apilar(int x);       // Pila inicializada.
    void desapilar();         // Pila inicializada y no vacía.
    int tope();               // Pila inicializada y no vacía.
    boolean pilaVacia();      // Pila inicializada.
}

3. Implementaciones

Con lista dinámica (LD)

El tope de la pila es el primer nodo de la lista enlazada. Apilar inserta adelante y desapilar saca el primero, así que todas las operaciones son O(1).

public class PilaLD implements PilaTDA {
    class Nodo { int valor; Nodo sig; }   // Cada nodo guarda un valor y apunta al siguiente.
    Nodo tope;                            // Referencia al primer nodo (el tope).

    public void inicializarPila() { tope = null; }      // Pila vacía = lista vacía (null).

    public void apilar(int x) {
        Nodo nuevo = new Nodo();
        nuevo.valor = x;
        nuevo.sig = tope;   // El nuevo apunta al viejo tope...
        tope = nuevo;       // ...y pasa a ser el nuevo tope.
    }

    public void desapilar() { tope = tope.sig; }        // El segundo nodo pasa a ser el tope.
    public int tope() { return tope.valor; }
    public boolean pilaVacia() { return tope == null; }
}

Con arreglo (A)

Se guarda un arreglo y un entero tope que indica la cantidad de elementos (y por lo tanto la próxima posición libre).

public class PilaA implements PilaTDA {
    int[] datos;
    int tope;   // Cantidad de elementos; el último válido está en datos[tope - 1].

    public void inicializarPila() { datos = new int[100]; tope = 0; }
    public void apilar(int x) { datos[tope] = x; tope++; }
    public void desapilar() { tope--; }
    public int tope() { return datos[tope - 1]; }
    public boolean pilaVacia() { return tope == 0; }
}

La pila es eficiente porque siempre trabaja sobre un solo extremo: no hay que recorrer nada.

5. Errores comunes

⚠️ Violar la precondición Llamar desapilar() o tope() con la pila vacía rompe el programa: NullPointerException en LD, o índice -1 en arreglo.
⚠️ No inicializar Usar la pila sin llamar antes a inicializarPila() deja tope en un estado inválido.
💡 Tip de parcial Antes de desapilar() o tope(), verificá siempre if (!pilaVacia()).

6. Resumen

  • LIFO: el último en entrar es el primero en salir.
  • Operaciones: apilar, desapilar, tope, pilaVacia, inicializarPila.
  • Todas O(1) tanto en lista dinámica como en arreglo.
  • Se trabaja siempre por un solo extremo (el tope).
