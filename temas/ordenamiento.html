Ordenamiento (Sorting)

1. ¿Qué es y cuándo se usa?

Ordenar es reacomodar los elementos de un arreglo siguiendo un criterio, típicamente de menor a mayor. Analogía: tenés cartas mezcladas en la mano y las vas acomodando hasta que quedan en orden.

Se usa para: dejar datos listos para una búsqueda binaria, mostrar resultados ordenados (rankings, listados), detectar duplicados o calcular la mediana. Es una de las operaciones más frecuentes, así que conviene saber qué algoritmo elegir según el caso.

5 1 4 2 8→ 1 2 4 5 8

2. Ideas clave

Casi todos los algoritmos se apoyan en dos operaciones básicas:

  • Comparar dos elementos para saber cuál va antes (a[i] > a[j]).
  • Intercambiar (swap) dos posiciones cuando están desordenadas.

Otras ideas importantes:

  • In-place: ordenar reusando el mismo arreglo, sin pedir memoria extra proporcional a n. Selección, inserción y burbuja son in-place; mergesort no.
  • Cuadráticos O(n²) (selección, inserción, burbuja): simples, pero lentos cuando n crece.
  • O(n log n) (quicksort, mergesort): basados en dividir y vencer, mucho más rápidos para arreglos grandes.
// Operación auxiliar usada por varios algoritmos: intercambia a[i] con a[j].
static void swap(int[] a, int i, int j) {
    int tmp = a[i];
    a[i] = a[j];
    a[j] = tmp;
}

3. Algoritmos (Java)

Selección (Selection Sort)

En cada vuelta busca el mínimo del tramo no ordenado y lo pone al principio. Hace pocos intercambios (uno por vuelta), pero siempre recorre todo para encontrar el mínimo.

static void seleccion(int[] a) {
    int n = a.length;
    for (int i = 0; i < n - 1; i++) {       // i marca el inicio del tramo desordenado.
        int min = i;                          // Suponemos que el mínimo está en i.
        for (int j = i + 1; j < n; j++) {     // Buscamos un valor menor en el resto.
            if (a[j] < a[min]) {
                min = j;                      // Encontramos un nuevo mínimo.
            }
        }
        swap(a, i, min);                      // Llevamos el mínimo a su posición final.
    }
}

Inserción (Insertion Sort)

Toma cada elemento y lo inserta en su lugar dentro del tramo ya ordenado de la izquierda, corriendo hacia la derecha los que son mayores. Es muy bueno cuando el arreglo ya está casi ordenado.

static void insercion(int[] a) {
    int n = a.length;
    for (int i = 1; i < n; i++) {            // a[0..i-1] ya está ordenado.
        int actual = a[i];                    // Valor a insertar.
        int j = i - 1;
        // Corremos a la derecha los mayores que 'actual'.
        while (j >= 0 && a[j] > actual) {
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = actual;                    // Hueco encontrado: insertamos.
    }
}

Burbuja (Bubble Sort)

Compara pares adyacentes y los intercambia si están desordenados. En cada pasada el mayor "burbujea" hasta el final. La bandera huboSwap permite cortar antes si ya quedó ordenado.

static void burbuja(int[] a) {
    int n = a.length;
    for (int i = 0; i < n - 1; i++) {        // Cantidad de pasadas.
        boolean huboSwap = false;
        for (int j = 0; j < n - 1 - i; j++) { // El tramo final ya está ordenado.
            if (a[j] > a[j + 1]) {
                swap(a, j, j + 1);
                huboSwap = true;
            }
        }
        if (!huboSwap) break;                 // Sin cambios ⇒ ya está ordenado.
    }
}

Quicksort

Elige un pivote, particiona el arreglo en menores y mayores que él, y se llama recursivamente sobre cada parte. Promedio O(n log n); el peor caso O(n²) aparece con pivotes muy desbalanceados (por ejemplo, arreglo ya ordenado).

static void quicksort(int[] a, int desde, int hasta) {
    if (desde >= hasta) return;              // Caso base: 0 o 1 elemento.
    int p = particion(a, desde, hasta);      // Deja el pivote en su lugar definitivo.
    quicksort(a, desde, p - 1);              // Ordena la parte izquierda (menores).
    quicksort(a, p + 1, hasta);              // Ordena la parte derecha (mayores).
}

// Esquema de Lomuto: usa el último elemento como pivote.
static int particion(int[] a, int desde, int hasta) {
    int pivote = a[hasta];
    int i = desde - 1;                        // 'i' marca el final de los menores.
    for (int j = desde; j < hasta; j++) {
        if (a[j] <= pivote) {
            i++;
            swap(a, i, j);                    // Mandamos el menor al sector izquierdo.
        }
    }
    swap(a, i + 1, hasta);                    // Colocamos el pivote tras los menores.
    return i + 1;                             // Posición final del pivote.
}

Mergesort

Divide el arreglo a la mitad, ordena cada mitad por recursión y luego las combina (merge) en orden. Es O(n log n) siempre, pero necesita un arreglo auxiliar (no es in-place).

static void mergesort(int[] a, int desde, int hasta) {
    if (desde >= hasta) return;              // Caso base: 0 o 1 elemento.
    int medio = (desde + hasta) / 2;
    mergesort(a, desde, medio);              // Ordena la mitad izquierda.
    mergesort(a, medio + 1, hasta);          // Ordena la mitad derecha.
    combinar(a, desde, medio, hasta);        // Mezcla las dos mitades ordenadas.
}

static void combinar(int[] a, int desde, int medio, int hasta) {
    int[] aux = new int[hasta - desde + 1];   // Arreglo auxiliar.
    int i = desde;        // Recorre la mitad izquierda.
    int j = medio + 1;    // Recorre la mitad derecha.
    int k = 0;            // Recorre el auxiliar.
    // Tomamos el menor de las dos mitades hasta agotar una.
    while (i <= medio && j <= hasta) {
        if (a[i] <= a[j]) aux[k++] = a[i++];
        else              aux[k++] = a[j++];
    }
    while (i <= medio)  aux[k++] = a[i++];     // Sobrantes de la izquierda.
    while (j <= hasta)  aux[k++] = a[j++];     // Sobrantes de la derecha.
    // Copiamos el resultado ordenado de vuelta al arreglo original.
    for (k = 0; k < aux.length; k++) {
        a[desde + k] = aux[k];
    }
}

💡 Regla práctica Para arreglos chicos o casi ordenados, insercion es simple y rápida. Para arreglos grandes, conviene un O(n log n): mergesort garantiza el costo siempre, y quicksort suele ser más veloz en la práctica pero tiene un peor caso O(n²).

5. Errores comunes

⚠️ Límites de los índices Confundir i < n con i <= n hace leer a[n], que no existe: ArrayIndexOutOfBoundsException. En burbuja, además, el interno va hasta j < n - 1 - i, no hasta n.
⚠️ Condición de corte mal puesta En inserción, olvidar el j >= 0 en el while hace acceder a a[-1]. Cuidado también con el orden: j >= 0 && a[j] > actual (primero el límite, después la comparación).
⚠️ Olvidar el caso base En quicksort y mergesort, sin if (desde >= hasta) return; la recursión nunca corta y revienta con StackOverflowError.
💡 Tip de parcial Trazá el algoritmo con un arreglo chico (4 o 5 elementos) y anotá el estado tras cada pasada o cada llamada recursiva. Es la forma más segura de detectar un índice o un corte mal puestos.

6. Resumen

  • Ordenar = reacomodar los elementos según un criterio (normalmente de menor a mayor).
  • Se basa en comparar e intercambiar; muchos algoritmos son in-place.
  • Cuadráticos O(n²): seleccion, insercion, burbuja — simples, para arreglos chicos.
  • O(n log n) por dividir y vencer: quicksort (promedio O(n log n), peor O(n²)) y mergesort (O(n log n) siempre, pero no in-place).
  • Los recursivos necesitan caso base; cuidá los límites de índices.
