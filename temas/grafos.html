Grafos

1. ¿Qué es y cuándo se usa?

Un grafo es un conjunto de vértices (nodos) conectados entre sí por aristas (conexiones). Cada arista puede tener un peso, un número que representa, por ejemplo, una distancia, un costo o una capacidad.

Hay dos variantes según la dirección de las aristas:

  • No dirigido: la arista entre A y B vale en los dos sentidos (si A está conectado con B, entonces B está conectado con A). Sirve para modelar relaciones simétricas, como amistades.
  • Dirigido (o dígrafo): la arista tiene un sentido. Que exista A → B no implica que exista B → A. Sirve para calles de mano única, dependencias entre tareas, etc.

Se usa para: mapas y rutas (ciudades = vértices, caminos = aristas con peso = distancia), redes (computadoras, redes sociales), dependencias entre tareas y muchos problemas de caminos mínimos.

2. Interfaz del TDA

Las operaciones del TDA Grafo y sus precondiciones. Los vértices se identifican con un entero (su etiqueta):

public interface GrafoTDA {
    void inicializarGrafo();                              // Sin precondiciones.
    void agregarVertice(int v);                           // Grafo inicializado.
    void eliminarVertice(int v);                          // Grafo inicializado y vértice existente.
    ConjuntoTDA vertices();                               // Grafo inicializado.
    void agregarArista(int origen, int destino, int peso);// Grafo inicializado, vértices existentes.
    void eliminarArista(int origen, int destino);         // Grafo inicializado, arista existente.
    boolean existeArista(int origen, int destino);        // Grafo inicializado, vértices existentes.
    int pesoArista(int origen, int destino);              // Grafo inicializado, arista existente.
}

vertices() devuelve un ConjuntoTDA con las etiquetas de todos los vértices del grafo: es la puerta de entrada para recorrerlo, porque te dice qué nodos existen.

3. Representaciones y recorridos (Java)

Matriz de adyacencia (MA)

Se usa una matriz mAdy de tamaño n×n (donde n es la cantidad de vértices). La celda mAdy[o][d] guarda el peso de la arista del vértice de índice o al de índice d. Un 0 significa "sin arista". Como los vértices se identifican por etiqueta pero la matriz trabaja con índices (0, 1, 2…), un método auxiliar vertice2indice traduce la etiqueta a su posición.

public class GrafoMA implements GrafoTDA {
    int[][] mAdy;       // Matriz n×n: mAdy[o][d] = peso de la arista o→d (0 = sin arista).
    int[] etiquetas;    // etiquetas[i] = nombre del vértice que vive en el índice i.
    int cantidad;       // Cantidad de vértices actuales.
    int mx = 55;        // Capacidad máxima.

    public void inicializarGrafo() {
        mAdy = new int[mx][mx];
        etiquetas = new int[mx];
        cantidad = 0;
    }

    public void agregarVertice(int v) {
        etiquetas[cantidad] = v;            // Guardo la etiqueta en la próxima posición libre.
        for (int i = 0; i <= cantidad; i++) {
            mAdy[i][cantidad] = 0;          // Su fila y columna arrancan sin aristas.
            mAdy[cantidad][i] = 0;
        }
        cantidad++;
    }

    public void agregarArista(int origen, int destino, int peso) {
        int o = vertice2indice(origen);
        int d = vertice2indice(destino);
        mAdy[o][d] = peso;                  // Cargo el peso en la celda correspondiente.
    }

    public void eliminarArista(int origen, int destino) {
        int o = vertice2indice(origen);
        int d = vertice2indice(destino);
        mAdy[o][d] = 0;                     // 0 vuelve a significar "sin arista".
    }

    public boolean existeArista(int origen, int destino) {
        int o = vertice2indice(origen);
        int d = vertice2indice(destino);
        return (mAdy[o][d] != 0);           // Hay arista si la celda no es 0.
    }

    public int pesoArista(int origen, int destino) {
        int o = vertice2indice(origen);
        int d = vertice2indice(destino);
        return mAdy[o][d];
    }

    private int vertice2indice(int v) {     // Traduce etiqueta → índice (busca linealmente).
        int i = cantidad - 1;
        while (i >= 0 && etiquetas[i] != v)
            i--;
        return i;
    }
}
💡 Dirigido vs no dirigido Como está, agregarArista sólo carga mAdy[o][d]: es un grafo dirigido. Para uno no dirigido, habría que cargar también mAdy[d][o] = peso (la matriz queda simétrica).

Lista de adyacencia (alternativa)

En lugar de una matriz, cada vértice guarda una lista con sus vecinos (y el peso de cada arista). Conviene cuando el grafo es ralo (pocas aristas): ocupa proporcional a la cantidad de aristas y no n². La contra es que averiguar si existe una arista puntual ya no es instantáneo: hay que recorrer la lista del vértice origen.

Recorrido en profundidad (DFS)

DFS (Depth-First Search) avanza por una rama todo lo que puede antes de retroceder. Es natural escribirlo de forma recursiva, usando un ConjuntoTDA de visitados para no procesar dos veces el mismo vértice:

void dfs(GrafoTDA g, int v, ConjuntoTDA visitados) {
    visitados.agregar(v);                 // Marco v como visitado.
    procesar(v);                          // Lo "uso" (imprimir, contar, etc.).

    ConjuntoTDA vs = g.vertices();        // Recorro todos los vértices buscando vecinos de v.
    while (!vs.conjuntoVacio()) {
        int w = vs.elegir();
        vs.sacar(w);
        if (g.existeArista(v, w) && !visitados.pertenece(w))
            dfs(g, w, visitados);         // Bajo recursivamente al vecino no visitado.
    }
}

Recorrido en amplitud (BFS)

BFS (Breadth-First Search) visita primero todos los vecinos directos, después los vecinos de esos, y así por "niveles". Se implementa con una Cola (FIFO) y el mismo conjunto de visitados:

void bfs(GrafoTDA g, int inicio) {
    ConjuntoTDA visitados = new ConjuntoLD();
    visitados.inicializarConjunto();
    ColaTDA cola = new ColaLD();
    cola.inicializarCola();

    cola.acolar(inicio);
    visitados.agregar(inicio);

    while (!cola.colaVacia()) {
        int v = cola.primero();
        cola.desacolar();
        procesar(v);

        ConjuntoTDA vs = g.vertices();    // Encolo los vecinos de v aún no visitados.
        while (!vs.conjuntoVacio()) {
            int w = vs.elegir();
            vs.sacar(w);
            if (g.existeArista(v, w) && !visitados.pertenece(w)) {
                visitados.agregar(w);     // Marco al encolar para no encolarlo dos veces.
                cola.acolar(w);
            }
        }
    }
}

4. Costo

Con V = cantidad de vértices. La matriz de adyacencia paga espacio para ganar velocidad al consultar una arista:

OperaciónMatriz de adyacencia
EspacioO(V²)
existeArista / pesoAristaO(1) tras ubicar el índice
Recorrer los vecinos de un vérticeO(V)
DFS (recorrido completo)O(V²)
BFS (recorrido completo)O(V²)

DFS y BFS cuestan O(V²) con matriz porque por cada uno de los V vértices hay que revisar su fila entera (otros V posibles vecinos). Con lista de adyacencia los recorridos bajan a O(V + A), donde A es la cantidad de aristas.

5. Errores comunes

⚠️ Olvidar el conjunto de visitados Si DFS o BFS no marcan los vértices ya procesados, ante un ciclo vuelven a entrar a los mismos nodos una y otra vez: bucle infinito. El conjunto de visitados es obligatorio.
⚠️ Operar aristas con vértices inexistentes agregarArista, existeArista, etc. asumen que origen y destino ya existen. Si pasás una etiqueta que no está, vertice2indice devuelve -1 y se accede a la matriz con índice negativo. Verificá la precondición antes.
⚠️ Confundir dirigido con no dirigido En un grafo no dirigido hay que cargar las dos celdas (mAdy[o][d] y mAdy[d][o]). Cargar sólo una lo convierte sin querer en dirigido y los recorridos "no encuentran" la conexión en el otro sentido.
💡 Tip de parcial Recordá que 0 es el valor centinela de "sin arista". Si en tu problema un peso legítimo puede ser 0, vas a necesitar otro valor (por ejemplo, -1) para marcar la ausencia.

6. Resumen

  • Un grafo son vértices unidos por aristas (con peso), y puede ser dirigido o no dirigido.
  • Operaciones del TDA: inicializarGrafo, agregarVertice, eliminarVertice, vertices, agregarArista, eliminarArista, existeArista, pesoArista.
  • Matriz de adyacencia: matriz n×n, celda = peso (0 = sin arista); existeArista O(1) pero O(V²) de espacio. La lista de adyacencia conviene para grafos ralos.
  • Recorridos: DFS (recursivo, en profundidad) y BFS (con cola, en amplitud); ambos necesitan un conjunto de visitados y cuestan O(V²) con matriz.
