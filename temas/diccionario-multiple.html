Diccionario Múltiple

1. ¿Qué es y cuándo se usa?

Un diccionario múltiple asocia cada clave con un conjunto de valores (clave → varios valores). Es la generalización del diccionario simple, donde cada clave tenía un solo valor (clave → 1 valor).

Analogía: una materia (la clave) tiene asociado un conjunto de alumnos (sus valores). La materia "Programación 2" no apunta a un único alumno, sino a todos los que la cursan. Como los valores forman un conjunto, no hay repetidos ni importa el orden.

Se usa cuando una entidad se relaciona con muchas otras: un autor con sus libros, un día con sus turnos, una categoría con sus productos.

clave 7 → {1, 4, 9}→ clave 3 → {2}→ null

2. Interfaz del TDA

Las operaciones del TDA Diccionario Múltiple y sus precondiciones. Notá que recuperar y claves devuelven un ConjuntoTDA, porque los valores de una clave (y las claves entre sí) forman conjuntos:

public interface DiccionarioMúltipleTDA {
    void inicializarDiccionario();              // Sin precondiciones.
    void agregar(int clave, int valor);         // Diccionario inicializado.
    void eliminar(int clave);                   // Diccionario inicializado.
    void eliminarValor(int clave, int valor);   // Diccionario inicializado.
    ConjuntoTDA recuperar(int clave);           // Diccionario inicializado.
    ConjuntoTDA claves();                       // Diccionario inicializado.
}

Ojo: recuperar(clave) / getValues(key) devuelven un conjunto de valores (sin repetidos). En la mayoría de los apuntes getValues devuelve Set, pero en algún examen aparece devolviendo List en vez de Set: verificá el apéndice de tu enunciado antes de asumir el tipo de retorno. En Monzón remove hace de eliminarValor (saca un solo valor); el borrado de la clave entera lo cubre el invariante que vemos abajo, no un método aparte.

Cosas importantes para el parcial:

  • agregar(clave, valor) agrega un valor al conjunto de esa clave. Si la clave no existía, la crea.
  • eliminar(clave) borra la clave entera (con todos sus valores).
  • eliminarValor(clave, valor) saca un solo valor del conjunto de esa clave.
  • recuperar(clave) devuelve el conjunto de valores de esa clave. Si la clave no existe, devuelve un conjunto vacío (no rompe).
  • claves() devuelve el conjunto de todas las claves del diccionario.

El invariante de oro: nunca una clave sin valores

La regla que rige toda la estructura: una clave existe si y solo si tiene al menos un valor. No hay claves "vacías". Esto separa con claridad dos operaciones que es fácil confundir:

  • eliminar(clave): borra la clave entera, con todos sus valores de una. Es el "borrá toda esta fila".
  • eliminarValor(clave, valor): saca un solo valor del conjunto de esa clave. Si después de sacarlo la clave queda con el conjunto vacío, hay que borrar la clave entera (justamente para no violar el invariante). En ese caso límite, eliminarValor termina llamando a eliminar(clave).
💡 Regla práctica Después de cada eliminarValor, preguntate: "¿la clave quedó con cero valores?". Si la respuesta es sí, la clave debe desaparecer. Una clave sin valores no tiene sentido y rompe el invariante: a partir de ahí claves() devolvería una clave que recuperar contesta como vacía.

3. Implementaciones

Con lista dinámica (LD)

Conviven dos tipos de nodos. NodoClave es la columna vertebral: forma una lista de claves. Cada NodoClave arranca su propia lista de NodoValor, que guarda su conjunto de valores. Es decir, una lista de listas.

public class DicMúltipleLD implements DiccionarioMúltipleTDA {

    class NodoClave {        // Una clave, su lista de valores y la siguiente clave.
        int clave;
        NodoClave sigClave;
        NodoValor valores;   // Inicio de la lista de valores de esta clave.
    }

    class NodoValor {        // Un valor del conjunto y el siguiente valor.
        int valor;
        NodoValor sigValor;
    }

    NodoClave inicio;        // Inicio de la lista de claves (toda la estructura).

    public void inicializarDiccionario() { inicio = null; }   // Diccionario vacío = lista vacía.

    public void agregar(int clave, int valor) {
        NodoClave nodo = clave2NodoClave(clave);   // Busca la clave...
        if (nodo == null) {                        // ...si no existe, la crea al inicio.
            nodo = new NodoClave();
            nodo.clave = clave;
            nodo.sigClave = inicio;
            inicio = nodo;
        }
        NodoValor turista = nodo.valores;          // Busca el valor en el conjunto de la clave.
        while (turista != null && turista.valor != valor)
            turista = turista.sigValor;
        if (turista == null) {                     // Si no estaba, lo agrega adelante (sin repetir).
            NodoValor nuevo = new NodoValor();
            nuevo.valor = valor;
            nuevo.sigValor = nodo.valores;
            nodo.valores = nuevo;
        }
    }
}

El método privado clave2NodoClave recorre la lista de claves y devuelve el NodoClave buscado, o null si no existe:

private NodoClave clave2NodoClave(int clave) {
    NodoClave turista = inicio;
    while (turista != null && turista.clave != clave)
        turista = turista.sigClave;
    return turista;   // El nodo de la clave, o null si no está.
}

recuperar ubica la clave y vuelca todos sus valores en un ConjuntoTDA nuevo. Si la clave no existe, devuelve el conjunto vacío:

public ConjuntoTDA recuperar(int clave) {
    ConjuntoTDA valores = new ConjuntoAR();
    valores.inicializarConjunto();
    NodoClave nodo = clave2NodoClave(clave);
    if (nodo != null) {                       // Si existe, copia su lista de valores al conjunto.
        NodoValor turista = nodo.valores;
        while (turista != null) {
            valores.agregar(turista.valor);
            turista = turista.sigValor;
        }
    }
    return valores;
}

Al borrar un valor, si la clave queda con el conjunto vacío, se elimina la clave entera:

public void eliminarValor(int clave, int valor) {
    NodoClave nodo = clave2NodoClave(clave);
    if (nodo.valores.valor == valor) {        // Caso especial: es el primer valor de la lista.
        nodo.valores = nodo.valores.sigValor;
    } else {
        NodoValor turista = nodo.valores;     // Busca el valor mirando hacia adelante.
        while (turista.sigValor != null && turista.sigValor.valor != valor)
            turista = turista.sigValor;
        if (turista.sigValor != null)         // Si lo encuentra, lo circunvala.
            turista.sigValor = turista.sigValor.sigValor;
    }
    if (nodo.valores == null)                 // Si la clave quedó sin valores, se la elimina.
        this.eliminar(clave);
}

Con arreglo (A)

El diccionario es un arreglo de objetos Elemento. Cada Elemento tiene una clave, su propio arreglo de valores y un contador cantValores. Una variable cantClaves indica cuántos elementos (claves) hay cargados.

public class DicMúltipleA implements DiccionarioMúltipleTDA {

    class Elemento {       // Una clave con su colección de valores.
        int clave;
        int[] valores;     // Arreglo con los valores de esta clave.
        int cantValores;   // Cantidad de valores cargados.
    }

    Elemento[] elementos;  // Arreglo de claves.
    int cantClaves;        // Cantidad de claves del diccionario.

    public void inicializarDiccionario() {
        elementos = new Elemento[55];   // Tamaño arbitrario, suficientemente grande.
        cantClaves = 0;
    }

    public void agregar(int clave, int valor) {
        int posClave = clave2Índice(clave);    // Busca la clave en el arreglo.
        if (posClave == -1) {                  // Si no existe, crea un Elemento nuevo al final.
            posClave = cantClaves;
            elementos[posClave] = new Elemento();
            elementos[posClave].clave = clave;
            elementos[posClave].valores = new int[33];
            elementos[posClave].cantValores = 0;
            cantClaves++;
        }
        int posValor = valor2Índice(elementos[posClave], valor);
        if (posValor == -1) {                  // Si el valor no estaba, lo agrega al final.
            elementos[posClave].valores[elementos[posClave].cantValores] = valor;
            elementos[posClave].cantValores++;
        }
    }
}

Para eliminar (clave o valor) se usa el truco de reemplazar con el último y decrementar el contador, evitando correr todo el arreglo:

public void eliminar(int clave) {
    int posClave = clave2Índice(clave);
    if (posClave != -1) {                          // Sobreescribe la clave con la última y achica.
        elementos[posClave] = elementos[cantClaves - 1];
        cantClaves--;
    }
}

Ejemplo estrella: armar el diccionario de sinónimos

Este ejercicio cae literal en los finales (apareció textual en el final de mayo de 2026). Es el ejemplo perfecto de composición: combina un Diccionario Simple, un Diccionario Múltiple y un recorrido destructivo de un conjunto.

Enunciado. Tenemos un Diccionario Simple D que modela el diccionario clásico: la clave es una palabra y su valor es su significado (palabra → significado). Queremos generar un Diccionario Múltiple DS que, dado un significado s, devuelva todas las palabras que comparten ese significado (sus sinónimos). O sea: en DS la clave es el significado y los valores son las palabras (significado → {palabras}). Lo que en D era el valor pasa a ser la clave de DS, y al revés.

La idea: recorrer todas las claves de D (las palabras). Para cada palabra, pedimos su significado a D y hacemos agregar(significado, palabra) en DS. Como recorremos un conjunto, usamos el patrón copia + iteración destructiva: pedimos claves() (un ConjuntoTDA), y mientras no esté vacío elegimos un elemento y lo sacamos de la copia, así no modificamos D:

public DiccionarioMúltipleTDA sinónimos(DiccionarioSimpleTDA d) {
    DiccionarioMúltipleTDA ds = new DicMúltipleLD();
    ds.inicializarDiccionario();

    ConjuntoTDA palabras = d.claves();        // Copia de las claves de D (las palabras).
    while (!palabras.conjuntoVacío()) {        // Iteración destructiva sobre la COPIA.
        int palabra = palabras.elegir();      // Elijo una palabra cualquiera...
        palabras.sacar(palabra);              // ...y la saco de la copia (D no se toca).

        int significado = d.recuperar(palabra);   // En D, la palabra → su significado.
        ds.agregar(significado, palabra);         // En DS, el significado → esa palabra.
    }
    return ds;
}

Por qué funciona, paso a paso:

  • Recorremos el ConjuntoTDA de claves con el patrón clásico while (!conjuntoVacío()) { elegir / sacar }. Trabajamos sobre la copia que devuelve claves(), no sobre D, así que D queda intacto.
  • El valor de D (el significado) se vuelve la clave de DS; la clave de D (la palabra) se vuelve un valor de DS. Es la inversión clave↔valor.
  • agregar en DS se encarga del resto: si el significado todavía no era clave de DS, la crea; si ya existía, suma la palabra a su conjunto sin repetir. Dos palabras con el mismo significado terminan juntas bajo la misma clave: son sinónimas.

Ejemplo: si D tiene "auto"→3, "coche"→3, "can"→7 (con 3 = "vehículo" y 7 = "perro"), el resultado es DS con 3→{auto, coche} y 7→{can}.

💡 Patrón a memorizar Este ejercicio ilustra la composición Diccionario → Conjunto → iteración destructiva. Casi todos los ejercicios de "transformar un diccionario en otro" salen con el mismo esqueleto: pedí las claves(), recorrelas con elegir/sacar sobre la copia, y por cada una consultá el original y volcá en el resultado.

4. Costo

Con n claves y m valores por clave. Ubicar la clave es siempre lineal (hay que recorrer la lista o el arreglo de claves), y a eso se le suma el costo de operar sobre su conjunto de valores.

OperaciónLista dinámica (LD)Arreglo (A)
inicializarDiccionarioO(1)O(1)
agregarO(n + m)O(n + m)
eliminarO(n)O(n)
eliminarValorO(n + m)O(n + m)
recuperarO(n + m²)O(n + m²)
clavesO(n²)O(n²)

Detalle: recuperar y claves usan el agregar del conjunto, que es lineal porque chequea repetidos. Por eso aparece el término cuadrático (m² al armar los valores, n² al armar las claves).

5. Errores comunes

⚠️ Recuperar de una clave inexistente No asumas que la clave existe. En estas implementaciones recuperar de una clave que no está devuelve un conjunto vacío; no rompe, pero si tu lógica espera valores vas a leer un conjunto vacío sin darte cuenta.
⚠️ Olvidar borrar la clave sin valores Al hacer eliminarValor del último valor de una clave, hay que decidir qué pasa. Acá la convención es: si la clave queda con el conjunto vacío, se elimina la clave entera (if (nodo.valores == null) eliminar(clave)). Si no lo hacés, te quedan claves "fantasma" sin valores.
⚠️ Mezclar clave y valor En agregar(int clave, int valor) el orden importa: el primer parámetro es la clave, el segundo el valor. Invertirlos rompe toda la estructura sin dar error de compilación.
💡 Tip de parcial Pensalo como "lista de listas": la lista de claves por afuera y, colgando de cada clave, su conjunto de valores. agregar primero resuelve la clave y recién después toca el conjunto.

6. Resumen

  • Asocia cada clave con un conjunto de valores (clave → varios valores).
  • Operaciones: agregar, eliminar, eliminarValor, recuperar, claves, inicializarDiccionario.
  • recuperar y claves devuelven un ConjuntoTDA.
  • LD: lista de NodoClave, cada una con su lista de NodoValor. A: arreglo de Elemento, cada uno con su arreglo de valores.
  • Costo: O(n) para ubicar la clave, más el costo de operar su conjunto de valores.
