# Guía de estudio — Programación 2 (Java / Algoritmos y Estructuras de Datos)

Guía interactiva y **offline** para repasar Programación 2: teoría de TDAs (Pila, Cola,
Cola de Prioridad, Conjunto, Diccionarios, Árboles, Grafos) y fundamentos (recursividad,
complejidad, ordenamiento).

- **Abrir local:** doble clic en `index.html` (no necesita servidor ni internet).
- **Online:** GitHub Pages.

Sin dependencias, sin build: HTML + CSS + JavaScript vanilla. El menú, el tema claro/oscuro,
el progreso y el resaltado de Java los maneja `assets/app.js` leyendo `assets/data.js`.
